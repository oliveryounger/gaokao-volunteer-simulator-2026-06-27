# 高考志愿填报模拟器

真实高校名称 + 平行志愿流程的娱乐模拟网页小游戏。玩家以“现在的上班族身份”重开一次高考，先查询一个大跨度模拟高考分和位次，再在仿志愿填报系统里填 6 个本/专科平行志愿，最后查看录取、调剂、退档或滑档结果，并生成另一条人生时间线。

数据与规则：

- 高校名称、学校标识码、所在地、主管部门：参考教育部《全国普通高等学校名单（截至2026年6月17日）》。
- 填报规则：参考阳光高考网关于平行志愿“冲、稳、保”、志愿顺序、服从调剂、一轮投档等策略说明。
- 投档位次、专业线、录取结果：全部为游戏模拟参数，不是真实招生数据。

核心机制：

- 模拟查分：按省份、科类、查分姿势、现世身份和重开剧本生成总分和位次，分数可覆盖低分、边缘分、高分与顶格爽文。
- 人生变量：现世身份、重开剧本、家庭情况、性格画像、特长标签会影响分数、志愿体检、自动填报和毕业走向。
- 院校检索：扩展真实高校卡池，覆盖 985、211/双一流、普通本科、民办本科、职业本科/高职；可按学校、城市、风险、层次筛选。
- 院校梗：每所学校展示轻量娱乐介绍，帮助玩家浏览时形成“抽卡”和“人生路线”感。
- 志愿表：6 个平行志愿槽位，可上移、下移、删除、切换服从调剂。
- 投档模拟：按 A-F 顺序检索，够线即投档；专业线不够时看是否服从调剂。
- 仪式揭晓：提交志愿后显示正式系统式投档流程，再揭晓录取结果。
- 人生时间线：结果页输出初始条件、录取大学、录取专业、院校梗、毕业职业倾向，以及 18 岁、22 岁、28 岁的另一条人生剧情。
- 分享传播：复制录取结果，下载包含初始条件、大学专业、院校梗、毕业走向的人生战报图。

安全边界：

- 不输入真实姓名、身份证号、准考证号。
- 不提供真实投档线、招生计划、录取概率或报考建议。
- 页面内明确标注“不构成真实志愿填报建议”。
